# JDWLABS-618: frontend dependency audit

Parent epic: JDWLABS-616 (minimise apps frontend dependencies, simplify the workspace structure).
Scope: JS/TS dependencies declared in the three `package.json` files and resolved in `pnpm-lock.yaml`. No code was changed.

## Method

- Declared: root `package.json` (17 `dependencies`, 68 `devDependencies`), `libs/frontend/shared/util/package.json`, `libs/frontend/shared/ui/package.json`. The workspace has no other `package.json`.
- Used: `git grep` over `apps/`, `libs/`, `tools/`, `scripts/` for imports, executors named in `project.json`/`nx.json`, config files and CI workflows.
- Resolved: `pnpm-lock.yaml` (1430 package entries) for duplicates and `overrides`.
- Classes: KEEP, USE-BUILT-IN (platform or framework feature replaces it), BUILD-IN-HOUSE (small enough to own), DROP (unused or redundant).
- "Verify" marks a recommendation that needs a build or test run before the change lands; this spike did not run installs or builds.

## Headline findings

1. **Eight overrides have no matching package in the lockfile**: `axios`, `form-data`, `hono`, `@hono/node-server`, `ip-address`, `systeminformation`, `tar`, `uuid`. They pin nothing and can be deleted.
2. **Four runtime packages can go**: `jwt-decode`, `ngx-cookie-service`, `@angular/material-moment-adapter` (which is the only reason `moment` is installed), and `@angular/platform-browser-dynamic` (never imported).
3. **Nine dev dependencies have no reference anywhere**: `autoprefixer`, `postcss`, `postcss-url`, `html-webpack-plugin`, `webpack-cli`, `ts-node`, `@nx-tools/container-metadata`, `@nx-tools/nx-container`, `commitizen` (script only). Several are probably pulled in by Angular/Nx anyway; removing the direct pin is the change.
4. **Runtime dependencies sit in `devDependencies`**: `jwt-decode` and `ngx-cookie-service`. Library `package.json` files duplicate root versions.
5. **The largest single dependency is `ag-grid-*`**: used by five components in rolesui/usersui. It is a product decision, not a quick win (see below).

## Duplicates

- `@angular/cdk` and `@angular/material` appear in both `dependencies` and `devDependencies` of the root manifest. Keep one entry in `dependencies`.
- `@angular/*` and `@material/*` versions are repeated in `libs/frontend/shared/util/package.json` and `shared/ui/package.json` as exact pins that must be bumped together with the root (Renovate groups them). The `shared/ui` peer list is the legitimate publishable-library form; `shared/util` also lists `dependencies` for a package that is `private` and never published, so those could be removed once the two lib `package.json` files are dropped.
- Lockfile version splits worth knowing about: `@babel/core` (7.29.7, 8.0.1, 8.0.5), `js-yaml` (4.3.2, 5.5.0), `brace-expansion` (1.1.21, 2.1.7, 5.0.12), `http-proxy-middleware` (3.0.10, 4.2.0), `ws` (8.21.3, 8.22.0), `postcss`, `autoprefixer`, `yaml`. Most are transitive and fall out as the direct pins above are removed; none is fixable by editing a direct dependency.

## Suggested order of work

1. Delete the eight stale overrides and the unreferenced dev dependencies (`autoprefixer`, `postcss`, `postcss-url`, `html-webpack-plugin`, `webpack-cli`, `@nx-tools/*`, `commitizen`, `cz-conventional-changelog`, `@angular/platform-browser-dynamic`, duplicate `@angular-eslint/*` and `@typescript-eslint/*`). Run `pnpm install`, then build and test everything.
2. Replace `jwt-decode` and `ngx-cookie-service` with in-house helpers.
3. Replace `MomentDateAdapter` with the native adapter; drop `moment` and the adapter package.
4. Drop `@angular/animations` and the four `provideAnimations()` calls.
5. Longer follow-ups, each its own ticket: container off webpack module federation (removes `@angular-devkit/build-angular`, `webpack`, `@module-federation/enhanced`, the webpack override), zoneless, and the ag-grid decision.
